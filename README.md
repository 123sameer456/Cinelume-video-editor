# Auto Video Editor: Phase Plan

Local-first web app (React + FastAPI + FFmpeg + faster-whisper) that takes a talking-style social video and automatically:

1. removes audio noise
2. cuts long silences, with a fade at every join
3. burns animated word-highlight subtitles (free, local Whisper)
4. mixes low-volume background music
5. creates a cover image from a frame with text on it

Every step has user-changeable options. Long videos are split into chunks and processed in parallel.

## How to use with an AI coder

1. Always put `README.md`, `00-architecture.md`, `00-options-schema.md` in context.
2. Give ONE phase file at a time. Do not start the next phase until every acceptance criterion of the current one passes.
3. Prompt template:

```
You are implementing Phase N of the attached plan. Follow 00-architecture.md rules strictly.
Implement every task and every edge case listed in the phase. Write the tests listed.
Do not add features that are not in the plan. If something is ambiguous, pick the safest
default, document it in docs/decisions.md, and continue.
When done, list each acceptance criterion with PASS/FAIL and how you verified it.
```

## Global rules (apply to every phase)

- **G1 Duration-aware:** memory use must stay flat no matter how long the video is. Never load a whole video or audio file into RAM. Stream or process in blocks.
- **G2 FFmpeg calls:** argument lists only (never `shell=True`), per-job `cwd`, timeout scaled to duration, stderr written to a per-job log, progress parsed from `-progress pipe:1`.
- **G3 Idempotent + resumable:** each stage writes to `*.partial` then atomically renames, and writes a `.done` marker containing the hash of the options that affect it.
- **G4 Cancel-safe:** cancelling kills the whole child process tree (psutil) and removes partial files.
- **G5 Options only via the validated pydantic model.** No magic constants in stage code.
- **G6 Windows first:** `pathlib`, multiprocessing `spawn`, spaces and unicode in paths, no POSIX-only calls.
- **G7 Free and local only:** no paid API, no cloud calls (except one-time model download).
- **G8 Tests use synthetic media** generated by FFmpeg `lavfi`, so no big fixtures are needed.
- **G9 Structured errors:** `{code, message, stage, chunk?, hint}` so the UI can show a useful message.
- **G10 Single chunk is not a special case.** A short video is just a plan with one chunk through the same code path.
